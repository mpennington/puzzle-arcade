# Puzzle Arcade

A self-contained logic-puzzle arcade — **Queens**, **Mini Sudoku**, **Tango**, and **Wend** — each with a teaching "Coach" that explains the next move instead of just filling in the answer.

Single file, no build step, no dependencies beyond web fonts. Just open `index.html`.

**Play it:** https://mpennington.github.io/puzzle-arcade/

## Games
- **Queens** — one queen per row, column, and colored region; none touching.
- **Mini Sudoku** — 6×6, with a highlight toggle and completion animations.
- **Tango** — fill the grid with Suns and Moons under the = / × clues.
- **Wend** — trace winding paths to uncover the hidden words.

Every puzzle has a unique, logically-solvable solution.
